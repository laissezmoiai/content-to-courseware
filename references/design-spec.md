# 课件视觉规范

速读课件的视觉目标：**读者的眼睛不需要找路**。

## 布局

- 内容宽度上限 `820px`，居中；两侧留白不做任何装饰
- 屏间距 `72px`；屏内元素间距 `16 / 24 / 40` 三档，不出现第四档
- 每屏只有一个视觉焦点（标题或一张卡），其余元素降一级

## 字体

| 用途 | 字号 / 字重 / 行高 |
|---|---|
| 课件主标题 | 40px / 700 / 1.15 |
| 节标题 | 28px / 600 / 1.3 |
| 卡片标题 | 18px / 600 / 1.4 |
| 正文 | 16px / 400 / 1.75 |
| 标注 / 出处 | 13px / 400 / 1.5 |

字体族：`-apple-system, "PingFang SC", "Microsoft YaHei", sans-serif`
数字与英文用等宽可选：`ui-monospace, SFMono-Regular, Menlo`

## 颜色

只允许三层：

- 背景 `#FAFAF8`
- 正文 `#1A1A1A`，次级 `#6B6B6B`
- 强调色**一个**：`#2F5D50`（仅用于结论句、序号、左边框）

五个以上颜色 = 没有重点。

## 卡片

- 无圆角或 4px 微圆角，不做大圆角药丸
- 不使用投影；用 `1px solid #E5E5E0` 区分层次
- 左侧 3px 强调色竖条标示卡片类型：框架=实线、原则=实线、案例=虚线、反例=深灰实线

## 信息密度

- 单屏正文 ≤ 180 字
- 一张卡 ≤ 120 字
- 列表最多 5 项，第 6 项开始考虑分组

## 禁止项

- 渐变、玻璃拟态、发光边框
- emoji 当图标
- 装饰性插图（除了材料本身的关键画面截图）
- 自动播放动画 / 滚动视差

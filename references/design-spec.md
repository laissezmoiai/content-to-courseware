# 课件视觉规范

速读课件的视觉目标：**读者的眼睛不需要找路**。

（2026-11-17 随 P1 模板重做同步更新：旧版强调色 #2F5D50、4px 圆角、禁药丸的规定作废，以本版为准。）

## 布局

- 内容宽度上限 `860px`，居中
- 每屏只有一个视觉焦点（标题或一张卡），其余元素降一级
- 卡片间距 `16px`，节间距 `24px`，屏间距用节内边距 `28px` 表达

## 字体

| 用途 | 字号 / 字重 / 行高 |
|---|---|
| 课件主标题 | 28px / 700 / 1.3 |
| 节标题 | 22px / 600 / 1.3 |
| 卡片标题 | 17px / 600 / 1.4 |
| 正文 | 14px / 400 / 1.7 |
| 标注 / 出处 / 图注 | 12–13px / 400 / 1.5 |

字体族：`"PingFang SC", "Microsoft YaHei", sans-serif`
编号与编号徽标：`monospace`

## 颜色

四层，各自有职责：

- 页面背景 `#F7F6FB`，卡片/头部白底
- 正文 `#1A1A2E`，次级 `#666` / `#999`
- 强调色**一个**：`#4A3F9F`（标签徽标、行内字段名、出处链接、竖条）
- 功能底色三块：目标 `#EEF7EE`、练习 `#FDF6E9`、速查 `#EEF2FB`（只用于这三处，不做装饰）

## 卡片

- 圆角 `10px`；类型徽标为药丸形（accent 底白字），放在卡片右上 `.cap` 行
- 无投影；层次用 `1px solid #E3E0EF` 边框 + 白底区分
- 步骤列表 `ol.steps` 左缩进 22px

## 信息密度

- 单屏正文 ≤ 180 字
- 一张卡（结论+展开）≤ 160 字，以 SKILL.md 阶段 2 为准
- 列表最多 5 项，第 6 项开始考虑分组

## 禁止项

- 渐变、玻璃拟态、发光边框
- emoji 当图标
- 装饰性插图（除了材料本身的关键画面截图）
- 自动播放动画 / 滚动视差
- 强调色第二来源（任何新颜色先改本规范再进模板）
